# Anderson Projetos — site

Site profissional do Anderson: serviços, projetos (cases) e contato.

- **Textos, serviços, cases e contatos:** edite só o arquivo `conteudo.ts`.
- **Imagens dos cases:** coloque em `public/cases/` e aponte em `imagem` no case.
- **Mostrar/esconder um case:** mude `publicar` para `true` ou `false`.

## Rodar localmente
```bash
npm install
npm run dev
```

Publicado na Vercel (Next.js).
